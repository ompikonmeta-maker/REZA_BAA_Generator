Easing & duration

Sistem kurva klasik MD3. Standard untuk gerakan UI umum, Emphasized untuk momen penting/hero, Linear hanya untuk progres indeterminate. Klik kartu untuk memutar kurvanya.

Easing tokens

* Emphasized aslinya kurva dua-bagian; di web diaproksimasi ke satu cubic-bezier. Untuk fidelitas penuh, pisah jadi emphasized-decelerate (masuk) & emphasized-accelerate (keluar).

Duration tokens

Prinsip: gerakan lebih besar → durasi lebih panjang (proporsional). Pasangkan masuk (decelerate) & keluar (accelerate).
