Belum terkategori

Semua fitur foto tetap ada, dikemas ke tile kompak:
• Klik tile = Edit/sesuaikan (reposisi/zoom/crop)  •  ⋯ = Baca SN, Isi SN ke Inventory, Ganti foto, Hapus
• ✓ = sudah terisi  •  strip SN (kategori OCR) tampil di bawah tile, klik untuk koreksi  •  Hapus → undo bercincin timer di dalam tile
• Tile kosong = klik untuk unggah  •  foto belum terkategori punya menu "Pindah kategori"
